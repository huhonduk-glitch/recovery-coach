## 0. 검수를 부탁드리는 이유

이 앱은 사용자가 설문에 답하면 **운동 루틴과 영양 가이드를 추천**합니다.
진단·치료·처방은 하지 않으며, 위험 신호가 있으면 운동을 제공하지 않고 상담을 안내합니다.

**문제는 아래 기준들이 아직 임상 근거로 검증된 값이 아니라는 점입니다.**
기획 단계에서 정한 값이며, 이대로 학생에게 쓰면 위험할 수 있습니다.

그래서 다음을 봐 주시기를 부탁드립니다.

| # | 검수 항목 | 이 문서의 위치 |
|---|---|---|
| 1 | 위험 신호 12개 문항이 충분하고 적절한가 | §1 |
| 2 | 위험도 분류(4단계) 기준이 타당한가 | §2 |
| 3 | 통증 점수별 단계 배정 기준이 타당한가 | §3 |

## 2. 위험도 분류 (4단계)

| 판정 | 분류 | 조건 | 앱의 반응 |
|---|---|---|---|
|  | **Red** | 위험 신호 1개 이상 **또는** 통증 7점 이상 | 운동 제공 중단, 상담 안내 |
|  | **Yellow** | 통증 4~6점, 또는 붓기·당일 발생·상시 통증 | 저강도 회복운동 (Phase 1) |
|  | **Green** | 통증 0~3점, 위험 신호 없음 | 회복·교정 운동 |
|  | **Performance** | 통증 0점 + 주 3회 이상 운동 + 수행능력/근력 목표 | 기능성 운동 |

**여쭙고 싶은 것** — Yellow 로 보내는 "급성 신호"(붓기 있음 / 오늘 발생 / 항상 아픔)의
조합이 적절합니까? 이 중 Red 로 올려야 할 것이 있습니까?

## 3. 통증 점수별 단계 배정

통증 척도는 0~10 이며, 화면에는 숫자와 함께 아래 라벨을 같이 보여 줍니다.

| 점수 | 화면 라벨 |
|---|---|
| 0 | 통증 없음 |
| 1~3 | 신경 쓰이지만 생활은 가능 |
| 4~6 | 움직일 때 꽤 아픔 |
| 7~8 | 많이 아픔, 생활이 어려움 |
| 9~10 | 참기 어려움 |

| 판정 | 최고 통증 점수 | 앱의 반응 | 현재 기준값 |
|---|---|---|---|
|  | 7점 이상 | 운동 제공 안 함, 상담 안내 | `PAIN_STOP_THRESHOLD = 7` |
|  | 4~6점 | Phase 1 (통증 완화/가동성) | `PAIN_PHASE1_THRESHOLD = 4` |
|  | 1~3점 | Phase 2 (안정화/활성화) | `PAIN_PHASE2_THRESHOLD = 1` |
|  | 0점 | 회복운동 대상 아님, 목표별 루틴 | — |

**여쭙고 싶은 것**

- 차단 기준을 7점으로 두는 것이 타당합니까? 더 낮춰야 합니까?
- 통증 4~6점 사용자에게 Phase 1 을 제공하는 것이 적절합니까?
- 3개월 이상 지속되는 통증은 점수와 무관하게 차단해야 합니까?
  (현재는 통증 점수만 봅니다)

## 4. 운동 중 통증 대응

운동 중 언제든 "통증 체크" 를 누를 수 있고, 응답에 따라 아래처럼 반응합니다.

| 판정 | 통증 점수 | 앱의 반응 |
|---|---|---|
|  | 0~3점 | 현재 루틴 유지 |
|  | 4~5점 | 횟수 절반, 가동범위 축소, 쉬운 동작으로 변경 |
|  | 6점 이상 | 해당 운동 중단, 기록 저장, 상담 안내 |

**운동 후**: 통증이 운동 전보다 높으면 다음 루틴 강도를 낮춥니다.

**여쭙고 싶은 것** — 중단 기준 6점이 적절합니까? 운동 후 통증 증가가 반복될 때
몇 회에서 상담으로 보내야 합니까? (현재는 다음 루틴 강도 하향만 합니다)
