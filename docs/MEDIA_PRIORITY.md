# 동작 이미지·영상 제작 우선순위

> `npm run media:priority` 로 자동 생성됩니다. 직접 고치지 마세요.

86개를 한 번에 준비할 필요는 없습니다. **위에서부터** 채우면 됩니다.
하나만 넣어도 그 운동만 영상·사진으로 바뀌고, 나머지는 글 설명 그대로 동작합니다.

## 순위를 정한 기준

추측이 아니라 **추천 엔진이 실제로 어떤 루틴을 먼저 내보내는지**로 정했습니다.

| 순서 | 묶음 | 왜 먼저인가 |
|---|---|---|
| 1 | 부위별 Phase 1 | 통증 4~6점 사용자가 처음 만나는 루틴 |
| 2 | 체형교정 | 통증 없는 사용자의 기본 루틴 (빠른 시작 기본값) |
| 3 | 부위별 Phase 2 | 통증 1~3점 사용자의 루틴 |
| 4 | 동적웜업 | 유연성 목표 또는 수업 전 준비운동 |
| 5 | 부위별 Phase 3 | 회복이 진행된 뒤 |
| 6 | 기능성 운동 | 통증 없이 수행능력을 올리려는 사용자 |
| 7 | 부위별 Phase 4 | 복귀 단계. 가장 나중 |

부위 순서는 `무릎 → 허리 → 발목 → 어깨 → 목·등 상부` 로 두었습니다.
학교 현장 기준의 운영상 판단이며, 임상 통계가 아닙니다.
바꾸시려면 `scripts/generate-priority.mjs` 의 `REGION_ORDER` 만 고치면 됩니다.
