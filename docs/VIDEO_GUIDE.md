# 동작 영상 연결 가이드

앱은 영상을 **가지고 있지 않습니다.** 링크만 보관하고, 누르면 유튜브가 열립니다.

---

## 1. 저작권 — 되는 것과 안 되는 것

| | 가능 여부 | 설명 |
|---|---|---|
| 유튜브 링크를 앱에 넣고 눌러서 열기 | ✅ 가능 | 원작자 채널에서 재생되고 조회수도 원작자에게 갑니다 |
| 유튜브 검색 결과 페이지 열기 | ✅ 가능 | 지금 앱에 이미 들어가 있습니다 |
| 영상 파일을 내려받아 앱에 넣기 | ❌ **저작권 침해** | 절대 하지 마세요 |
| 남의 영상을 편집해 다시 올리기 | ❌ **저작권 침해** | |
| 인스타그램 릴스 임베드 | ⚠️ 권장하지 않음 | 앱 안 임베드는 약관 위반 소지가 있습니다. 링크 열기만 쓰세요 |
| 썸네일 이미지를 저장해 앱에 넣기 | ❌ 하지 마세요 | 썸네일도 저작물입니다 |

> 정리: **링크는 되고, 파일은 안 됩니다.**

---

## 2. 영상을 고르는 기준

### ⚠️ 조회수 순으로 고르지 마세요

회복운동 분야에서 조회수가 높은 영상은 대체로 이런 특징이 있습니다.

- 자극적인 제목과 썸네일 (`3일 만에`, `이것만 하면`)
- 통증이 있어도 밀어붙이는 동작
- 제품·강의 판매로 이어지는 구성

조회수는 **참고 지표**로만 쓰고, 아래 기준을 먼저 봅니다.

### 확인 순서

| 순서 | 확인할 것 | 왜 |
|---|---|---|
| 1 | 만든 사람이 물리치료사·재활 전문가·병원인가 | 자세 정확도의 최소 조건 |
| 2 | 우리 앱의 동작 설명과 자세가 같은가 | 다르면 사용자가 헷갈립니다 |
| 3 | "아파도 참고", "끝까지" 같은 말이 없는가 | 통증을 참게 하면 위험합니다 |
| 4 | 중단 기준이나 주의사항을 말해 주는가 | 좋은 영상의 특징입니다 |
| 5 | 광고·판매 유도가 심하지 않은가 | 학생이 볼 화면입니다 |
| 6 | 길이가 3분 이내인가 | 길면 안 봅니다 |
| 7 | 한국어인가 | 영어면 앱에 '영어 영상' 이라고 표시됩니다 |

### 이런 영상은 연결하지 마세요

- 통증을 참으라고 하는 영상
- 진단명을 단정하는 영상 (`이건 디스크입니다`)
- 특정 제품·보조제를 파는 영상
- 자세가 우리 앱 설명과 명백히 다른 영상
- 얼굴이 나오는 학생·미성년자가 모델인 영상

---

## 3. 영상 연결하는 방법

```
1. 유튜브에서 영상을 찾습니다.
2. 주소를 복사합니다.
3. src/data/exerciseVideos.ts 에 한 줄 추가합니다.

   'knee-p1-01': {
     url: 'https://www.youtube.com/watch?v=xxxxx',
     title: '쿼드셋 시연',
     source: '○○ 물리치료',
     korean: true,
   },

4. npm run videos:check 로 확인합니다.
```

등록하지 않은 운동에는 **"유튜브에서 찾아보기"** 버튼이 나옵니다.
검색어에 `재활 운동 방법` 이 자동으로 붙어서, 자극적인 운동 영상보다 재활 성격의
영상이 위로 오게 되어 있습니다.

---

## 4. 앱 화면에 나가는 안내

영상을 연결하면 화면에 이렇게 표시됩니다.

> 영상은 만든 분의 채널에서 재생됩니다.
> 앱의 글 설명과 자세가 다르면 글 설명을 따라 주세요.

연결하지 않았을 때는 이렇게 표시됩니다.

> 검색 결과는 앱이 검증하지 않았습니다.
> 통증을 참으라거나 무리하라는 영상은 따라 하지 마세요.

**글 설명이 항상 기준입니다.** 영상은 보조 자료입니다.

---

## 5. 검수와의 관계

영상 링크도 콘텐츠입니다. 운동 내용과 마찬가지로 **전문가 검수 대상**입니다.
검수 전에는 `docs/VIDEO_CANDIDATES.md` 에 후보로만 두고, 확인이 끝난 것만
`exerciseVideos.ts` 로 옮기세요.
