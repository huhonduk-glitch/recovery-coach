# 리커버핏 Coach — 콘텐츠 작성 가이드

> 문서 버전: v0.1 (초안)
> 최종 수정: 2026-09-02
> 대상: 운동·영양 콘텐츠를 작성·검수하는 사람 (본인 + 검수 전문가)

---

## 1. 이 문서의 목적

앱의 품질은 **콘텐츠 품질**이다. 화면이 예뻐도 동작 설명이 부정확하면 사용자가 다친다.
이 문서는 운동·영양 콘텐츠를 **같은 형식, 같은 기준, 같은 톤**으로 쓰기 위한 규칙이다.

콘텐츠는 코드가 아니라 데이터다(`src/content/`). 개발자가 아니어도 수정할 수 있어야 한다.

## 2. 운동 콘텐츠 구조

### 2.1 카테고리 8종

| 카테고리 | 코드값 | 목적 |
|---|---|---|
| 체형교정 | `posture` | 자세 정렬 개선, 습관성 불균형 관리 |
| 동적웜업 | `dynamicWarmup` | 본운동 전 체온·가동범위 준비 |
| 기능성 운동 | `functional` | 일상·스포츠 동작 수행 능력 |
| 어깨 회복운동 | `shoulderRecovery` | 어깨 통증 후 단계적 회복 |
| 허리 회복운동 | `lowBackRecovery` | 허리 통증 후 단계적 회복 |
| 무릎 회복운동 | `kneeRecovery` | 무릎 통증 후 단계적 회복 |
| 발목 회복운동 | `ankleRecovery` | 발목 통증·불안정성 회복 |
| 목/등 상부 회복운동 | `neckUpperBackRecovery` | 목·등 상부 통증 회복 |

### 2.2 회복운동 4단계 (Phase) 정의

> 5개 회복 카테고리(어깨·허리·무릎·발목·목/등상부)는 **모두 4단계 구조**를 가진다.
> 체형교정·동적웜업·기능성 운동은 Phase 대신 난이도 3단계(초/중/상)로 운영한다.

#### Phase 1 — 통증 완화 / 가동성 회복
| 항목 | 내용 |
|---|---|
| 목표 | 자극을 줄이고 움직임을 되찾는다 |
| 성격 | 통증 없는 범위의 가동, 호흡, 부드러운 이완 |
| 강도 | 매우 낮음. 통증 0~2 범위 안에서만 |
| 대표 형태 | 관절 가동 운동, 이완, 호흡, 통증 없는 등척성 시작 |
| 금지 | 저항 부하, 최대 가동범위 밀어붙이기, 반동 |
| 진행 기준(초안) | 통증 증가 없이 6회 이상 수행 |

#### Phase 2 — 안정화 / 근육 활성화
| 항목 | 내용 |
|---|---|
| 목표 | 관절을 잡아주는 근육을 다시 깨운다 |
| 성격 | 낮은 부하 등척성·저강도 저항, 자세 유지 |
| 강도 | 낮음. 수행 중 통증 증가 없어야 함 |
| 대표 형태 | 코어 안정화, 견갑 안정화, 밴드 저강도 저항 |
| 금지 | 중량 부하, 고속 동작 |
| 진행 기준(초안) | 통증 증가 없이 6회 이상 + 동작 수행이 편안함 |

#### Phase 3 — 근력 회복
| 항목 | 내용 |
|---|---|
| 목표 | 부상 전 수준의 근력에 다가간다 |
| 성격 | 점진적 저항, 전 가동범위 |
| 강도 | 중간. 통증 없이 수행 가능한 범위에서 점증 |
| 대표 형태 | 자체중량 근력, 밴드·덤벨 중강도 |
| 금지 | 통증 참고 수행, 급격한 중량 증가 |
| 진행 기준(초안) | 통증 증가 없이 8회 이상 + 양측 차이 감소 체감 |

#### Phase 4 — 기능 복귀 / 재발 예방
| 항목 | 내용 |
|---|---|
| 목표 | 일상·운동 동작으로 복귀하고 재발을 막는다 |
| 성격 | 복합 동작, 균형·협응, 낮은 수준의 속도 요소 |
| 강도 | 중간~높음 |
| 대표 형태 | 복합 하지 동작, 균형·고유수용성, 통제된 감속 동작 |
| 금지 | 통증 있는 상태에서 진입, Phase 1~3 건너뛰기 |
| 유지 | 재발 예방 루틴으로 주 1~2회 유지 권장 |

> Phase 진행 기준의 횟수(6회 / 8회)는 **설계 초안값**이다. 전문가 검수 후 확정한다.

## 3. 운동 데이터 스키마

```ts
export interface Exercise {
  id: string;               // 'knee-p1-01' 형식
  name: string;             // 한국어 동작명
  category: ExerciseCategory;
  phase: Phase;             // 1|2|3|4
  purpose: string;          // 왜 하는지, 한 문장
  cues: string[];           // 수행 방법 3~5개. 한 문장 한 지시
  cautions: string[];       // 주의사항 1~3개 (필수, 비워둘 수 없음)
  stopSigns: string[];      // 즉시 중단 신호 (필수, 비워둘 수 없음)
  reps?: number;
  sets?: number;
  holdSec?: number;
  restSec?: number;
  equipment: Equipment[];   // 없으면 ['none']
  image?: string;
  estimatedSec: number;     // 루틴 시간 계산용
  order: number;            // 루틴 내 정렬 순서 (셔플 금지)
}
```

### 3.1 ID 규칙
```
{부위코드}-p{Phase}-{순번2자리}
예) knee-p1-01, shoulder-p2-03, lowback-p3-02
체형교정·웜업·기능성: posture-l1-01, warmup-l2-02, functional-l3-01
```

### 3.2 작성 예시 (형식 참고용 — 내용은 검수 전 초안)
```ts
{
  id: 'knee-p1-01',
  name: '누워서 무릎 펴고 허벅지 앞 힘주기',
  category: 'kneeRecovery',
  phase: 1,
  purpose: '무릎을 움직이지 않고 허벅지 앞 근육을 깨워, 부담 없이 힘을 되찾습니다.',
  cues: [
    '바닥에 누워 무릎을 편 상태로 둡니다.',
    '무릎 뒤로 바닥을 가볍게 누른다는 느낌으로 힘을 줍니다.',
    '숨을 참지 말고 편하게 쉬면서 유지합니다.',
    '힘을 천천히 풀고 잠시 쉽니다.',
  ],
  cautions: [
    '무릎이 아픈 각도까지 억지로 펴지 않습니다.',
    '숨을 참지 않습니다.',
  ],
  stopSigns: [
    '무릎 안쪽이 찌르듯 아플 때',
    '힘을 줄 때 저림이 생길 때',
  ],
  sets: 2, reps: 10, holdSec: 5, restSec: 30,
  equipment: ['none'],
  estimatedSec: 180,
  order: 1,
}
```

### 3.3 필수 검증 규칙 (콘텐츠 린트)
- [ ] `cautions` 비어 있지 않음
- [ ] `stopSigns` 비어 있지 않음
- [ ] `cues` 3개 이상 5개 이하
- [ ] `purpose` 한 문장, 40자 내외
- [ ] `estimatedSec` 있음 (루틴 시간 계산 불가 방지)
- [ ] Phase 1~2 동작에 중량 장비(`dumbbell`) 미사용
- [ ] 금지 표현(SAFETY_POLICY §1.1) 미포함

## 4. 운동 문구 작성 규칙

### 4.1 큐(cue) 작성 원칙
1. **한 문장에 한 지시.** "무릎을 펴고 엉덩이를 들면서 배에 힘을 주세요" (✗) → 세 문장으로 분리.
2. **몸의 느낌으로 설명한다.** 해부학 용어 대신 "허벅지 앞", "어깨뼈 사이".
3. **순서대로 쓴다.** 준비 자세 → 동작 → 유지 → 복귀.
4. **호흡을 명시한다.** 등척성 동작에는 "숨을 참지 마세요"를 넣는다.
5. **숫자는 명확히.** "잠깐" (✗) → "5초 동안" (○).
6. **존댓말·권유형.** "펴세요" 보다 "펴 주세요", "~합니다".

### 4.2 톤 & 매너 — "옆에 있는 체육 선생님"
| 상황 | 이렇게 |
|---|---|
| 시작 | "오늘은 무리하지 않는 범위에서 가볍게 시작해요." |
| 수행 중 | "지금 통증이 늘어나면 바로 멈춰 주세요." |
| 완료 | "잘 하셨어요. 오늘 상태를 기록해 둘게요." |
| 통증 증가 시 | "오늘은 여기까지 하는 게 좋겠어요. 다음엔 한 단계 낮춰서 진행할게요." |
| 차단 시 | "지금은 앱보다 전문가의 확인이 먼저예요." |

**쓰지 않는 말**: "화이팅", "한계까지", "버티세요", "이 정도는 참을 만해요", "며칠이면 좋아져요"

### 4.3 이미지 규칙
- 시작 자세 1장 + 동작 최종 자세 1장 (최소).
- 얼굴이 식별되는 실사 사진은 사용하지 않는다 (초상권·개인정보).
- 일러스트 또는 실루엣 권장.
- 저작권: 직접 제작하거나 상업적 이용 가능 라이선스만. **출처를 콘텐츠 파일에 기록한다.**

## 5. 영양 콘텐츠 구조

### 5.1 트랙 4종

| 트랙 | 코드값 | 대상 | 핵심 메시지 |
|---|---|---|---|
| 다이어트 / 건강 체중관리 | `weightCare` | **성인 전용** | 굶지 않고 식사의 질을 바꾼다 |
| 벌크업 / 근육량 증가 | `bulkUp` | 성인 + 학생 | 끼니마다 단백질을 챙기고 총 식사량을 충분히 |
| 일반 건강식 | `general` | 전체 (학생 기본) | 규칙적으로, 골고루 |
| 회복 / 면역 / 미네랄 | `recovery` | 부상·회복기 | 단백질 + 채소·과일 + 수분 |

### 5.2 영양 데이터 스키마
```ts
export interface NutritionGuide {
  track: NutritionTrack;
  mode: Mode;                       // 'student' | 'adult'
  headline: string;                 // 한 줄 요약
  handPortions: HandPortionGuide;   // 손 기준 (전 모드 공통)
  foodExamples: { group: string; items: string[] }[];
  tips: string[];                   // 3~5개
  macroRatio?: { carb: number; protein: number; fat: number };  // 학생 모드 undefined
  calorieRange?: string;                                        // 학생 모드 undefined
  cautions: string[];
  sources: string[];                // 근거 출처 (필수)
}
```

### 5.3 손 기준 가이드 (전 모드 공통 표기)
| 영양소 | 기준 | 설명 문구 |
|---|---|---|
| 단백질 | 손바닥 1개분 | "고기·생선·달걀·두부 중 하나를 손바닥 크기만큼" |
| 채소 | 주먹 1~2개분 | "채소는 주먹 하나에서 둘 정도" |
| 탄수화물 | 주먹 1개분 | "밥·빵·면은 주먹 하나 정도부터" |
| 지방 | 엄지 1개분 | "기름·견과류는 엄지 한 마디 정도" |

> 이 손 기준은 **개인의 손 크기에 맞춘 상대적 기준**이라는 점을 함께 설명한다.

### 5.4 모드별 표시 규칙 (강제)

| 항목 | 학생 모드 | 일반 모드 |
|---|---|---|
| 칼로리 숫자 | **표시 안 함** | 참고 범위 + "참고용" 표기 |
| 다량영양소 비율(%) | **표시 안 함** (개념 설명만) | 표시 |
| 그램(g) 단위 | **표시 안 함** | 손 기준과 병기 |
| "체중"·"감량"·"칼로리" 단어 | **결과 화면 미노출** | 사용 가능 |
| `weightCare` 트랙 | **선택 불가 → `general` 대체** | 선택 가능 |

### 5.5 영양 문구 작성 원칙
1. **더하기 프레임.** "빵을 줄이세요" (✗) → "빵과 함께 달걀이나 우유를 곁들여 보세요" (○).
2. **음식에 도덕적 라벨을 붙이지 않는다.** "나쁜 음식", "치팅데이" 금지.
3. **개인 목표 수치를 정해주지 않는다.** 범위와 개념만 제시.
4. **한국 식생활 기준으로 예시를 쓴다.** 밥·김·두부·계란·나물 등.
5. **알레르기·제한 응답을 반영해 예시를 제외한다.**
6. **모든 수치에는 출처를 붙인다.** 출처 없는 수치는 넣지 않는다.

### 5.6 영양 콘텐츠 예시 (형식 참고 — 수치 미확정)
```ts
{
  track: 'general',
  mode: 'student',
  headline: '규칙적으로, 한 끼에 네 가지를 챙겨요.',
  handPortions: {
    protein: '매 끼 손바닥 1개분 (고기·생선·달걀·두부 중 하나)',
    vegetable: '매 끼 주먹 1~2개분',
    carb: '매 끼 주먹 1개분부터, 활동량이 많으면 더',
    fat: '하루 엄지 1~2개분',
  },
  foodExamples: [
    { group: '단백질', items: ['달걀', '두부', '닭가슴살', '생선', '우유·요거트'] },
    { group: '채소·과일', items: ['나물류', '샐러드 채소', '제철 과일'] },
    { group: '탄수화물', items: ['밥', '고구마', '통곡물 빵'] },
  ],
  tips: [
    '아침을 거르면 오후에 몰아 먹기 쉬워요. 간단하게라도 챙겨 보세요.',
    '운동한 날에는 단백질과 밥을 평소보다 조금 더 챙기면 회복에 도움이 돼요.',
    '물은 목이 마르기 전에 조금씩 나눠 마셔 주세요.',
  ],
  cautions: [
    '성장기에는 식사량을 크게 줄이지 않는 것이 중요해요.',
    '체중이나 식사 때문에 걱정이 크다면 보건 선생님이나 보호자와 상의해 주세요.',
  ],
  sources: ['(확정 전) 한국인 영양소 섭취기준 최신판 확인 필요'],
  // macroRatio, calorieRange 없음 — 학생 모드
}
```

## 6. 화면 문구(Copy) 가이드

### 6.1 문장 길이
- 버튼: 2~6자 ("시작하기", "다음", "중단")
- 안내 문장: 40자 이내
- 카드 본문: 2~3문장

### 6.2 자주 쓰는 문구 표준화
| 상황 | 표준 문구 |
|---|---|
| 설문 시작 | "몇 가지만 여쭤볼게요. 3~5분이면 끝나요." |
| 결과 요약 | "지금 상태를 이렇게 정리했어요." |
| 루틴 시작 전 | "통증이 늘어나면 언제든 멈춰 주세요." |
| 세션 완료 | "오늘 루틴을 마쳤어요. 상태를 기록해 둘게요." |
| Phase 상승 제안 | "지금 단계가 편해지신 것 같아요. 다음 단계로 올려 볼까요?" |
| Phase 하향 | "최근에 통증이 늘었어요. 한 단계 낮춰서 진행할게요." |
| 데이터 삭제 확인 | "기록이 모두 지워지고 되돌릴 수 없어요. 진행할까요?" |

### 6.3 숫자 표기
- 통증: 숫자 + 라벨 항상 병기 ("6 · 움직일 때 꽤 아픔")
- 시간: "5초", "30초", "3분"
- 횟수: "10회 × 2세트"

## 7. 콘텐츠 제작 순서 (MVP)

```
1) 부위별 Phase 1 동작 4~6개씩  ← 최우선. 이것만 있어도 앱이 돌아간다
2) 부위별 Phase 2 동작 4~6개씩
3) 동적웜업 1세트 (6~8동작)
4) 체형교정 1세트 (6~8동작)
5) 영양 4트랙 × 학생/일반 = 8개 가이드
6) Phase 3~4 (MVP 이후)
7) 기능성 운동 (MVP 이후)
```

## 8. 콘텐츠 검수 체크리스트

### 8.1 자가 점검 (작성자)
- [ ] 금지 표현(SAFETY_POLICY §1.1)이 없다
- [ ] `cautions`, `stopSigns` 가 모두 채워져 있다
- [ ] 큐가 한 문장 한 지시로 되어 있다
- [ ] Phase 정의(§2.2)와 동작 강도가 맞는다
- [ ] 학생 모드 금지 항목(칼로리·체중·감량)이 없다
- [ ] 수치에 출처가 있다
- [ ] 이미지 저작권이 확인되었다

### 8.2 전문가 검수 (외부)
| 검수자 | 검수 범위 |
|---|---|
| 건강운동관리사 / 운동처방 전공자 | Phase 구분 타당성, 동작 선택, 진행 기준 |
| 물리치료사 / 재활 전문가 | 레드 플래그 목록, 통증 컷오프, 회복 동작 적절성 |
| 의사 (재활의학·정형외과) | 차단 기준, 면책 문구, 의료 표현 경계 |
| 영양사 / 영양 전공자 | 영양 트랙, 손 기준 가이드, 청소년 영양 안전성 |
| (권장) 법률 검토 | 의료법·표시광고법 관점 문구 검토 |

### 8.3 검수 기록 방식
각 콘텐츠 파일 상단에 주석으로 남긴다.
```ts
/**
 * 검수 상태: 미검수 | 1차 검수 완료 | 확정
 * 검수자 역할: (예) 물리치료사
 * 검수일: YYYY-MM-DD
 * 주요 수정: ...
 */
```
> **미검수 콘텐츠로는 스토어 출시하지 않는다.**
