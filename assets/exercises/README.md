# 운동 동작 이미지 폴더

이 폴더에 운동 사진이나 일러스트를 넣습니다.

## 파일 이름
운동 id 와 똑같이 지어 주세요. 확장자는 `.png` 또는 `.webp` 를 권장합니다.

```
knee-p1-01.png      무릎 1단계 첫 번째 운동
shoulder-p2-03.png  어깨 2단계 세 번째 운동
posture-01.png      체형교정 첫 번째 운동
```

어떤 id 가 필요한지는 저장소 최상단의 `docs/IMAGE_LIST.md` 에 전부 적혀 있습니다.

## 넣은 뒤 할 일
`src/data/exerciseImages.ts` 파일을 열어 한 줄을 추가합니다.

```ts
'knee-p1-01': require('../../assets/exercises/knee-p1-01.png'),
```

등록하지 않으면 앱에서는 부위 표시 그림이 대신 나옵니다.

## 이미지 규격 (권장)
| 항목 | 값 |
|---|---|
| 비율 | 4:3 가로 |
| 크기 | 긴 변 1200px 내외 |
| 용량 | 장당 200KB 이하 |
| 배경 | 단색, 밝은 색 |

## 반드시 지킬 것
- **얼굴이 알아볼 수 있게 나온 사진을 쓰지 않습니다.** (초상권·개인정보)
  얼굴이 나오면 잘라내거나, 실루엣·일러스트로 대체하세요.
- **학생을 모델로 쓰지 않습니다.** 꼭 필요하면 본인과 보호자 동의를 먼저 받으세요.
- 직접 제작했거나 상업적 이용이 가능한 라이선스의 이미지만 씁니다.
- 출처가 있으면 `docs/IMAGE_LIST.md` 의 비고란에 적어 두세요.
