# 리커버핏 Coach (recovery-coach)

간단한 설문으로 현재 몸 상태를 확인하고, **운동 추천 · 회복 루틴 · 영양 가이드**를 안내하는 모바일 앱입니다.
학교 체육교사가 옆에서 코칭해 주는 느낌으로, 앱 화면만 보고도 안전하게 운동할 수 있도록 만드는 것이 목표입니다.

> **현재 상태: M2 완료** — 안전 레이어(동의·스크리닝·차단)가 동작합니다.
> 부위별 설문과 추천 로직, 운동 콘텐츠는 아직 없습니다 (M3 이후).

---

## ⚠️ 먼저 읽어 주세요

이 앱은 **의료기기가 아니며, 의학적 진단·치료·처방을 제공하지 않습니다.**

- 제공하는 것: 일반적인 **운동 추천**, **회복 루틴**, **영양 가이드**, **기록 도구**
- 제공하지 않는 것: 진단, 치료, 처방, 병명 판정, 응급 대응
- 위험 신호가 확인되면 **운동 루틴을 제공하지 않고 전문가 상담을 안내**합니다.
- 이미 진료를 받고 있다면 **의료진의 지시가 항상 우선**합니다.

자세한 기준은 [docs/SAFETY_POLICY.md](docs/SAFETY_POLICY.md) 를 참고하세요.

## 핵심 원칙

| # | 원칙 |
|---|---|
| 1 | 의학적 진단·치료·처방을 하지 않는다 |
| 2 | 화면에서는 "처방"이 아니라 "운동 추천 / 회복 루틴 / 영양 가이드"라고 쓴다 |
| 3 | 위험 신호가 있으면 루틴을 주지 않고 전문가 상담으로 안내한다 |
| 4 | 학생 사용자에게 무리한 다이어트·칼로리 제한을 유도하지 않는다 |
| 5 | 1차 버전은 서버 없이 **기기 로컬 저장**만 사용한다 |
| 6 | 추천은 AI 생성이 아니라 **안전한 룰 기반 엔진**으로 만든다 |
| 7 | UI는 깔끔하고 신뢰감 있게, 코칭하는 톤으로 만든다 |
| 8 | 한국어 UI 기본 |

## 주요 기능 (계획)

1. 온보딩
2. 안전 안내 및 동의
3. 초기 설문 (안전 스크리닝 → 부위·통증 → 활동·목표 → 영양)
4. 운동 추천 결과
5. 운동 루틴 실행 화면
6. 영양 추천 결과
7. 기록 화면
8. 설정 화면

### 운동 카테고리
체형교정 · 동적웜업 · 기능성 운동 · 어깨 회복 · 허리 회복 · 무릎 회복 · 발목 회복 · 목/등 상부 회복

### 회복운동 4단계 구조
| 단계 | 내용 |
|---|---|
| Phase 1 | 통증 완화 / 가동성 회복 |
| Phase 2 | 안정화 / 근육 활성화 |
| Phase 3 | 근력 회복 |
| Phase 4 | 기능 복귀 / 재발 예방 |

### 영양 트랙
다이어트·건강 체중관리 (성인 전용) · 벌크업/근육량 증가 · 일반 건강식 · 회복/면역/미네랄

> **학생 모드**에서는 칼로리 숫자 대신 **손바닥 / 주먹 / 엄지 기준**의 균형식 가이드를 제공합니다.

## 개인정보 / 건강정보 취급

- 설문 응답과 운동 기록은 **기기 안에만 저장**되며 외부로 전송되지 않습니다.
- 이름·연락처·학번·소속 학교는 **입력받지 않습니다.**
- 이 저장소에는 **실제 사용자 데이터를 올리지 않습니다.**
- `.env`, 서명 키, 인증서는 `.gitignore` 로 커밋을 차단합니다.

## 실행 방법

```bash
npm install        # 필요한 라이브러리 설치 (처음 한 번)
npx expo start     # 개발 서버 실행 → 폰의 Expo Go 앱으로 QR 스캔
```

확인용 명령어

```bash
npm run typecheck  # 타입 오류 검사
npm run lint       # 코드 규칙 검사
npm test           # 테스트 실행
```

### 폴더 구조

```
app/          화면 (파일 이름 = 주소, Expo Router)
src/theme/    색상·글자·간격 토큰
src/types/    도메인 타입
src/storage/  로컬 저장소 (AsyncStorage 래퍼 + repository)
src/engine/   룰 기반 판정 로직 (safety/ 구현됨, 추천 로직은 M3)
src/content/  운동·영양·문구 데이터
docs/         기획 문서
```
